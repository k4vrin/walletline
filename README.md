# WalletLine

Financial managment app built completely with KMP (Jetpack Compose + SwiftUi).

## Tech Stack and Libraries

-   [Kotlin](https://kotlinlang.org/)

-   [Swift](https://kotlinlang.org/)

-   [Jetpack Compose](https://developer.android.com/jetpack/compose) Jetpack Compose is Android’s modern toolkit for building native UI

-   [SwiftUi](https://developer.apple.com/xcode/swiftui) SwiftUI helps you build great-looking apps across all Apple platforms with the power of Swift.

-   [Koin](https://insert-koin.io/) The pragmatic Kotlin & Kotlin Multiplatform Dependency Injection framework.

-   [SqlDelight](https://sqldelight.github.io/sqldelight/2.0.2/) SQLDelight generates typesafe Kotlin APIs from your SQL statements.

-   [Ktor](https://ktor.io/) Create asynchronous client and server applications. Ktor is built from the ground up using Kotlin and Coroutines.
